## How to use it

1. Fill in the number and expiry date of each document. Leave nothing blank: write "not applicable" where one does not apply.
2. Check each number in the public database where one exists, such as Info Alkes for the *izin edar* ([rule A.1](../regulation.html#rule-a-1)).
3. Check that every document names the same model as the offer.
