Device dossiers

A dossier is a short report on one device. It answers all three questions for that device, in a few pages, for a team that has to buy it.

What a dossier contains

PartQuestion it answersWhat it contains
SpecificationWhat should we ask for?A model specification that names no brand, the requirements that matter clinically, and the standards to name.
PricingWhat should it cost?Published reference prices, what each one includes, and why they differ.
ProcessHow do we buy it without a failed tender?How to divide the lots, how to score the bids, and the questions bidders usually ask.

How a dossier is made

Every dossier follows the same six steps, so any two can be compared and every claim can be traced.

  1. Public sources are collected, and each one is recorded with its link and the date it was read.
  2. The specification is written using the thirteen sections of the WHO template, the same for every device.
  3. The reference price is built from cited figures, each with what it includes.
  4. The draft is checked against the two publication rules below.
  5. Someone who uses the device in clinical practice reads it before it is published.
  6. It is published with a version number and a date, and corrections are recorded on the page.

When a dossier is published

A dossier is published only when both of these are true:

  • Everything in it comes from public documents, and each source is cited.
  • It is not about a tender that is still being evaluated.

Dossiers do not rate brands or recommend models. They describe what to ask for, what a fair price covers, and how to run the purchase.
